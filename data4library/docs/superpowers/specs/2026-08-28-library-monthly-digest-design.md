# 도서관 월간 트렌드 요약봇 설계

- 날짜: 2026-08-28
- 상태: 승인됨, 구현 계획 대기

## 목적

정보나루(data4library) MCP를 통해 매달 자동으로 "이달의 트렌드 키워드"와 "전국 인기 대출 도서 TOP 10"을 조회해 요약하고, 보관용 마크다운 파일과 시각적 대시보드(Artifact)로 남긴다. 완전히 읽기 전용이며, 별도 커스텀 코드 없이 Claude가 MCP 도구 호출 + 텍스트/HTML 종합을 수행하는 자동화 워크플로우다.

## 사용 MCP 도구 (data4library)

- 이달의 트렌드 키워드 조회
- 인기 대출 도서 조회 (전국 전체 기준, TOP 10)
- `get_book_keywords` (TOP 10 중 상위 5권에 대해서만 호출 — API 호출 절약)

## 구성 요소

1. **`.claude/skills/library-monthly-digest/SKILL.md`** — 이 저장소(`data4library`)에 두는 프로젝트 스킬. 실행 시 아래 "데이터 흐름"을 그대로 수행하는 절차서. 커스텀 파싱/렌더링 코드는 두지 않는다 — MCP 응답을 Claude가 직접 마크다운/HTML로 종합한다.
2. **`schedule` 스킬로 등록하는 크론 작업** — 매월 1일, 위 SKILL을 자동 실행.
3. **`data4library/digests/YYYY-MM.md`** — 매달 새로 쌓이는 보관용 마크다운 파일.
4. **대시보드 Artifact (HTML)** — 같은 내용을 시각화한 웹페이지. 매달 같은 URL로 재발행(redeploy)하며, 재발행 시 `"YYYY-MM"` 라벨을 붙여 Artifact 자체의 버전 선택기로 과거 달을 조회할 수 있게 한다.

## 데이터 흐름

1. "이달의 트렌드 키워드" 호출 → 이번 달 키워드 목록 획득
2. "인기 대출 도서 조회" 호출 (전국 전체, TOP 10) → 순위/도서명/저자/대출횟수 획득
3. TOP 10 중 상위 5권에 대해서만 `get_book_keywords` 호출 → 도서별 핵심 키워드 획득
4. 아래 형식으로 마크다운 종합:

```markdown
# 도서관 트렌드 요약 — 2026년 9월

## 이달의 트렌드 키워드
키워드1, 키워드2, 키워드3 ...

## 인기 대출 도서 TOP 10
1. 책제목 — 저자 (대출 1,234회)
2. 책제목 — 저자 (대출 987회)
...
10. ...

## TOP 5 핵심 키워드
1. 책제목: 키워드A, 키워드B
...
5. ...
```

5. **이중 출력**:
   - `data4library/digests/YYYY-MM.md`로 파일 저장 (매달 새 파일, 과거 달은 파일명으로 구분되어 항상 조회 가능)
   - 같은 내용을 대시보드 Artifact로 발행/재발행 — 트렌드 키워드 카드, TOP 10 랭킹 리스트(대출횟수 포함), TOP 5 키워드 태그를 한 화면에 배치

### Artifact URL 영속화

스케줄 실행은 매번 새 세션이므로 파일 경로만으로는 같은 Artifact를 갱신할 수 없다. **최초 실행 시 생성된 Artifact URL을 `data4library/digests/.dashboard-url` 파일에 저장**해두고, 이후 실행마다 이 파일을 읽어 해당 URL로 재발행(`Artifact` 도구의 `url` 파라미터)한다. 재발행 시 `label`에 `"YYYY-MM"`을 지정해 버전 선택기에서 월별 구분이 가능하게 한다.

## 에러 처리

- MCP 도구 호출 실패(인증키 만료/미등록, API 오류) 시 — 재시도나 추측성 fallback 없이, 어떤 도구가 왜 실패했는지 그대로 보고하고 중단한다.
- 트렌드 키워드 또는 인기 도서 목록이 비어 있는 경우 — "이번 달 데이터 없음"을 명시하고 빈 파일/빈 Artifact를 만들지 않는다.

## 전제 조건 (이 설계의 범위 밖)

- 정보나루 MCP 서버가 Claude Code에 이미 연결되어 있고 인증키가 유효해야 한다. 이 연결 설정 자체는 사용자가 사전에 완료해야 하는 부분이며 이 설계에 포함되지 않는다.

## 테스트 계획

- SKILL 작성 후 **수동으로 한 번 실행**하여 실제 MCP 응답으로 마크다운/Artifact가 의도대로 생성되는지, 파일 경로가 올바른지 확인한다.
- 수동 실행이 정상 동작한 뒤에만 `schedule` 스킬로 매월 1일 자동 실행을 등록한다.
- 별도 자동화 테스트 코드는 작성하지 않는다 — 커스텀 로직이 없고 MCP 호출 + 텍스트/HTML 종합뿐이라 스크립트 단위 테스트 대상이 없다 (YAGNI).

## 범위 밖 (Out of Scope)

- 카카오톡/슬랙/이메일 등 외부 채널 발송 (현재는 터미널/파일/Artifact만)
- 지역별(동네 도서관 단위) 필터링 (현재는 전국 전체 기준)
- 도서 대출 가능 여부, 도서관 검색 등 다른 MCP 도구 활용 (다른 아이템으로 별도 설계 대상)
